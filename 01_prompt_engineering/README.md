# Prompt Engineering Lab

A practical, engineering-focused repository for designing reliable and reusable prompts for Large Language Models (LLMs).

This repo covers:
- Core prompt engineering principles
- Reusable prompt patterns and templates
- Real-world use cases (summarization, inference, transformation, evaluation)
- Practical notebooks demonstrating prompt composition and iteration

---

## Repository Structure

- `01_prompt_engineering/`
  - `prompt-engineering-playbook.md`  
    A comprehensive reference covering principles, patterns, and reusable templates.
  - `00_guidelines.ipynb`  
    High-level prompting guidelines.
  - `01_iterative_prompt_development.ipynb`  
    Iterative prompt refinement workflows.
  - `02_summarizing.ipynb` – `06_chatbot.ipynb`  
    Concrete use cases and applied examples.

---

## How to Use

1. Start with **`prompt-engineering-playbook.md`** to understand core principles and patterns.
2. Explore the notebooks to see how these patterns are combined in practice.
3. Reuse and adapt the templates for your own LLM or agentic workflows.

## Who This Is For

- ML / DL engineers
- LLM application builders
- Agentic AI system designers
